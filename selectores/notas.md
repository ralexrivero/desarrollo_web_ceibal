# Selectores CSS

Recordar y diferencias los selectores basicos
- Etiquetas
- Clase
- ID

Comprender y aplicar selectores combinados

Introducir el concepto de pseudoclse
- `:hover`
- `:focus`

Especificidad de la selección, para saber quien gana cuando hay conflicto de estilos

## Etiqueta

**elemento**

```css
p {
    color: blue;
}
```

*Los uso cuando quiero hacer cambios globales*


## Clase 

>
> El más usado
>

```css
.tarjeta {
    background-color: #f0f0f0;
}
```

*Los uso cuando quiero aplicar un estilo a varios elementos diferentes*

## id

```css
#boton-enviar {
    width: 100%;
}
```

>
> El menos usado
>

*Los uso unicamente para estilos únicos*
